# Prompts de espiritualidade (modelo)

Vieram do meu-novo-lar, onde atendiam o "Mago da Meia Noite". Não pertencem a nenhum blog
ainda: ao criar um blog de espiritualidade/Umbanda, copie esta pasta `prompts/` para
`content/blogs/<subdominio>/prompts/` e marque as categorias SPIRITUAL_* no cadastro do blog.
